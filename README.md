# puntobec-linkedin

Publicaciones diarias de la página de LinkedIn de PuntoBEC: instrucciones, registro, aprendizajes e imagen de cada día.

- `INSTRUCCIONES.md`: proceso diario (lo leen las rutinas en la nube).
- `scripts/tarjeta.py`: generador de la imagen de cada publicación.
- `datos/`: registro, investigación, publicaciones, gráficos, métricas y respuestas propuestas.
